How the implied value is worked out

Implied value = TVL × benchmark × growth × age × breadth × category. The benchmark is the median market-cap-to-TVL ratio of the protocols in this same snapshot that already record a token, so the multiple is the market's own, not a picked number. Growth is the protocol's 7-day TVL change; age is how long it has run with no token recorded; breadth is how many chains it runs on; category compares its peers' 7-day change with the whole snapshot. Protocols that already record a token are counted below and set aside — they are not launches waiting to happen. “Records no token” means the snapshot carries no token for the protocol; it is not proof that none exists.
